# hidroBIntel

**Plataforma de Inteligencia Artificial para Hidrobart S.A. de C.V.**

---

hidroBIntel es el sistema nervioso digital de Hidrobart. Una plataforma interna desarrollada por **Philippe Abadie** que integra Agentes de IA autónomos y Asistentes inteligentes diseñados para empoderar a las personas en sus procesos diarios — desde costeo de productos hasta gestión de pedidos, clientes y operaciones aduanales.

> La IA no reemplaza al equipo: lo potencia.

---

## ¿Qué es hidroBIntel?

hidroBIntel nació como respuesta a una necesidad concreta: llevar la inteligencia artificial al interior de una empresa de distribución, de forma práctica, soberana y centrada en las personas.

No es un producto genérico. Es una plataforma construida desde adentro, con conocimiento profundo de los procesos de Hidrobart, y diseñada para crecer junto con la organización.

---

## Módulos activos

| Módulo | Descripción |
|--------|-------------|
| **Costeo360** | Sistema de costeo, pricing y catálogo de productos con factor comercial configurable |
| **CRM** | Gestión de clientes, contactos y seguimiento comercial |
| **Unidum** | Planificador de acciones y tareas con notificaciones y trazabilidad |
| **Agente Aduana** | Pipeline automatizado del ciclo aduanal completo — desde archivo M hasta extracción de XML/PDF |
| **HidroSSO** | Servicio de autenticación centralizado para todos los módulos |

---

## Stack tecnológico

- **Frontend:** Next.js (App Router) — desktop y mobile/PWA
- **Backend:** FastAPI — un servicio por dominio de negocio
- **Orquestación IA:** OpenClaw con Rocket.Chat como canal de interacción
- **Infraestructura:** Azure Linux VM (Ubuntu 24.04) — Canada Central
- **Bases de datos:** MySQL · MongoDB · Qdrant · Redis
- **CI/CD:** GitHub Actions con self-hosted runner en hidroSuiteVM

---

## Filosofía

- **IA soberana:** los datos de Hidrobart nunca salen de su infraestructura
- **Humano al centro:** los agentes asisten, las personas deciden
- **Privacidad por diseño:** repositorios privados, acceso controlado
- **Iteración continua:** cada módulo crece con el negocio
